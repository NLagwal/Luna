        \item Implemented \texttt{VectorService} (\path{src/services/vector.py}) interfacing with ChromaDB via HTTP with score thresholding.
        \item Populated \texttt{luna\_vault} collection with curated academic circulars and official university ordinances.

    \item \textbf{Vihaan Sharma (QA \& Testing):}

% WEEK 4
\subsection*{Week 4: Streaming Generation, Safety Valves \& Latency Profiling}
\noindent \textbf{Duration:} July 13, 2026 -- July 19, 2026 \hfill \textbf{Phase:} Streaming \& Safety \\
\textbf{Milestone:} Real-time token streaming endpoints, RapidFuzz name ambiguity handler, and performance profiling.

\subsubsection*{Individual Contributions:}
\begin{itemize}
    \setlength{\itemsep}{1pt}
    \item \textbf{Nakul Lagwal (AI Lead):}
    \begin{itemize}
        \setlength{\itemsep}{0pt}
        \item Engineered the \textbf{Fuzzy Name Safety Valve} in \path{src/services/db.py} using \path{rapidfuzz.process.extractOne} with \texttt{fuzz.WRatio}.
        \item Configured dual confidence thresholds: matches $\ge 80\%$ trigger direct profile retrieval; matches between $65\%$ and $79\%$ return interactive clarification prompts (\textit{``Did you mean Dr. [Name]?}).
        \item Implemented session-based conversational memory in \path{src/services/memory.py} using LangChain \texttt{ChatMessageHistory}.
    \end{itemize}

    \item \textbf{Kavish Bansal (Backend \& Database):}
    \begin{itemize}
        \setlength{\itemsep}{0pt}
        \item Developed asynchronous NDJSON streaming endpoint \texttt{POST /chat\_stream} in \path{src/api/chat.py} using FastAPI \texttt{StreamingResponse}.
        \item Integrated session lifecycle management ensuring thread-safe conversational histories per user.
        \item Implemented response formatters (\path{src/utils/formatter.py}) generating clickable source citations and mandatory Track B disclaimers.
    \end{itemize}

    \item \textbf{Vihaan Sharma (QA \& Testing):}
    \begin{itemize}
        \setlength{\itemsep}{0pt}
        \item Designed a dedicated edge-case test battery targeting misspelled faculty names, phonetic variations, and missing honorifics.
        \item Profiled time-to-first-token (TTFT) on \path{/chat_stream}, recording an average TTFT of $<350\text{ ms}$.
        \item Verified that the safety valve triggered reliably on 100\% of ambiguous test names without false-positive lockouts.
    \end{itemize}
\end{itemize}
\noindent \textbf{Weekly Review \& Outcome:} Real-time token streaming functioning. Interactive spelling ambiguity resolution validated.
